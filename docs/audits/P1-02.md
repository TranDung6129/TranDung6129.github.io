`aae95e9d6f397fd2262c8e3a3298a401253d8122`. P1-01 was accepted after
merged [PR #13](https://github.com/TranDung6129/TranDung6129.github.io/pull/13)

## Browser evidence, screenshots and performance

Headless Chromium exercises the unmodified production output via a local Python
HTTP server. Requests to third parties retain their normal destinations; there
is no production-origin rewrite, TLS bypass or mocked library. See
[browser report](p1-02/browser/REPORT.md) and
[raw browser results](p1-02/browser/results.json) for actual assertions, console
and network errors, navigation/paint timings and limitations.

Eight interaction assertions pass: Nash preset state, keyboard payoff slider,
TOC anchor, theme change, theme persistence, local search results, code rendering
and code copy. Copy requires opening the initially collapsed code block before
hovering its header. Earlier harness assumptions about theme attributes, number
formatting and collapsed code were corrected; those exploratory failures are not
website defects. MathJax typesetting and activity heatmap rendering do **not**
pass: blocked third-party loading leaves raw math and `CalHeatMap is not defined`.
Normal 404s for the known logo/poster defects are also retained in runtime errors.

The screenshot set covers home and Nash at 360, 768, 1024 and 1440px in light and
dark modes. These are screenshots of existing site output, not new editorial
illustrations. Cookie notices and failed external resources remain visible.
Integrator visually inspected mobile-light home and desktop-dark Nash; raw math
delimiters are visible when MathJax loading fails. No redesign or visual approval
is implied. Screenshots are viewport captures, not an exhaustive full-page audit.

Performance values are a **single local unthrottled headless-browser run**, with
failed external resources. They are diagnostic baseline observations, not field
Core Web Vitals, Lighthouse scores, production budgets or a performance pass.
In this run the home load event was 292.4ms/FCP 144ms; Nash load event
394.7ms/FCP 100ms. These numbers describe this machine/run only, with failed
external requests and ordinary browser cache state across page visits.
No full accessibility/contrast audit or live GitHub Pages deployment test is claimed.
