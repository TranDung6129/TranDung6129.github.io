## Configuration and deployment conclusions

Hugo **Extended 0.149.0**, matching the deployment pin, builds the project. This
machine has Node 24.22.1/npm 11.9.0; deployment specifies Node 20. npm dependencies
were installed with `npm ci`, preserving the lockfile. These are local build
results, not a claim that GitHub Actions or Pages ran successfully.

Isolation probes show `config/_default` overrides conflicting root settings,
while root-only values survive and theme defaults fill missing values. The
directory supplies title, two themes, search/Fuse and expanded menus; root still
supplies subject-section cascade, MathJax selection, Goldmark math/extras and
pagination 12. Removing either config family would change behavior. All 13 split
files and merge directives are enumerated in the detailed ledger.

`deploy.yml` builds on filtered main pushes, manual dispatch, and completion of
the theme updater; it has **no pull-request trigger**. A docs-only audit does not
match its main push filter. It checks out full history/submodules, installs the
pinned Hugo DEB, sets up Node 20, runs `npm ci` and the Hugo production build,
uploads `public/` and deploys Pages. No workflow changes are made here.

The daily updater runs at 00:00 UTC (07:00 Asia/Saigon), advances FixIt with
`--remote --merge`, and auto-commits. Its completion triggers deployment without
a success-outcome condition in the YAML. Dependabot separately proposes monthly
Actions/submodule updates; its `Lruihao` assignee is inherited starter metadata.
The workflows' operational settings and current live deployment were not
accessible through the GitHub API in this environment.

  ja/zh-cn homes do not imply translated articles exist. The generated home
  `<html lang>` values are vi/en/ja/zh-cn respectively; content translation quality
  and hreflang equivalents still require P1-02/P1-06 review.

  privacy.x setting also exists. `frontmatter.toml` retains `:defalut` typo.

  proof of successful third-party requests. Browser, keyboard, contrast,
  responsive screenshots, full link/fragment checking and measured performance
  belong to P1-02. No visual parity or interactive-simulation success is claimed.
- P1-03 must decide consolidation/template migration. This audit approves no
  new framework, CSS system, architecture, payments, affiliate or memberships.
