## Open gate

MathJax typesetting and CalHeatMap remain unverified in Chromium: external requests hit proxy tunnel or certificate failures. `curl` retrieves MathJax with the system CA and verified TLS, but Chromium's trust configuration did not; no TLS verification was disabled and no assets were substituted. Existing P1-02 missing assets, menu links, metadata duplicates, console failures and external loading failures remain. D-012 requires a trusted network-capable browser test before claiming parity. P1-04 remains BLOCKED until that evidence is supplied and reviewed; this report does not certify visual/accessibility parity or a live deployment.
